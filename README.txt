# LoomPredict

## تشغيل التطبيق على Windows

1. ثبتي Python 3.11 أو أحدث من https://www.python.org/downloads/
   أثناء التثبيت فعّلي اختيار **Add Python to PATH**.
2. فكّي ضغط ملف LoomPredict.zip في مجلد واضح.
3. افتحي المجلد، واضغطي في شريط العنوان واكتبي `cmd` ثم Enter.
4. اكتبي الأمرين دول بالترتيب:

```bash
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

5. هيفتح التطبيق في المتصفح تلقائيًا. لو ما فتحش، افتحي الرابط الظاهر في نافذة الأوامر وغالبًا يكون http://localhost:8501

## ملاحظات مهمة
- البيانات اللي تحفظيها في شاشة الماكينات وسجل الإنتاج بتتخزن محليًا داخل مجلد `data` على نفس الكمبيوتر.
- ملفات الكارت والخطة تُرفع من داخل التطبيق. في النسخة الأولية يتم الاحتفاظ بها داخل جلسة المتصفح الحالية؛ ارفعيها عند فتح جلسة جديدة.
- موعد الوردية تقديري لأن الإنتاج المدخل إجمالي يومي وليس مفصلًا حسب الوردية.
- معدلات الإنتاج المرجعية بوحدة الدستة/اليوم كما تم تحديدها، والتحويل إلى فردة يتم بالضرب في 24.
- راجعي كل نتيجة قبل إرسال خطة تغيير فعلية. هذا إصدار تأسيسي يحتاج مواءمة أسماء الأعمدة وقواعد الكميات بعد تجربة ملفات المصنع.
